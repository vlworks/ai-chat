# Self-Hosted AI Chat (Open WebUI + Caddy)

Веб-интерфейс **Open WebUI** с автоматическим выпуском SSL-сертификата через **Caddy** для работы с любым OpenAI-совместимым API (например, Timeweb Cloud AI Gateway).

## Структура проекта

```text
.
├── .env               # Локальные переменные и секреты (не отслеживается Git)
├── .env.example       # Шаблон переменных окружения
├── .gitignore         # Исключает .env из репозитория
├── Caddyfile          # Конфигурация обратного прокси и авто-HTTPS
├── docker-compose.yml # Описание сервисов Open WebUI и Caddy
└── README.md          # Документация проекта
```

## Требования

* VPS с установленными **Docker** и **Docker Compose** (рекомендуется от 2 ГБ ОЗУ, при активной работе с документами — 4 ГБ ОЗУ).
* Поддомен с настроенной **A-записью**, указывающей на IP-адрес сервера.
* Открытые входящие порты **80** и **443** на сервере (для работы HTTP/HTTPS и проверки Let's Encrypt).

## Быстрый старт

1. **Клонируйте или скопируйте проект на сервер:**
   ```bash
   mkdir -p /opt/ai-chat && cd /opt/ai-chat
   ```

2. **Создайте файл `.env` на основе шаблона:**
   ```bash
   cp .env.example .env
   ```

3. **Сгенерируйте секретный ключ сессий:**
   ```bash
   openssl rand -hex 32
   ```

4. **Заполните `.env` своими значениями:**
    * `DOMAIN` — ваш поддомен (например, `://example.com`)
    * `API_BASE_URL` — базовый URL OpenAI-совместимого API (например, `https://timeweb.ai`)
    * `API_KEY` — ваш API-ключ провайдера
    * `WEBUI_SECRET_KEY` — сгенерированная на шаге 3 строка

5. **Запустите контейнеры:**
   ```bash
   docker compose up -d
   ```

6. **Проверьте выпуск SSL-сертификата:**
   ```bash
   docker logs caddy
   ```

7. **Первичная настройка:**
    * Откройте `https://<ваш-домен>` в браузере.
    * Зарегистрируйте **первый аккаунт** — он автоматически получит права администратора.
    * Для остальных пользователей самостоятельная регистрация отключена (`ENABLE_SIGNUP=false`). Новых пользователей при необходимости можно добавить вручную в **Панели администратора -> Пользователи**.

## Полезные настройки после запуска

* **Поиск в интернете:** включается в **Панели администратора -> Настройки -> Поиск в интернете** (можно выбрать бесплатный движок `duckduckgo` без API-ключей), после чего в окне чата появится иконка глобуса.
* **Права доступа к моделям:** в **Панели администратора -> Настройки -> Модели** можно скрывать дорогие модели от обычных пользователей (`Private` или доступ по группам).

## Обслуживание

* **Просмотр логов:**
  ```bash
  docker compose logs -f
  ```

* **Обновление Open WebUI и Caddy до свежих версий:**
  ```bash
  docker compose pull && docker compose up -d
  ```

* **Перезапуск сервисов:**
  ```bash
  docker compose restart
  ```

## Резервное копирование базы чатов и настроек

Все чаты, пользователи и настройки хранятся в Docker-томе `open-webui-data`. Чтобы сделать бэкап в текущую папку:

```bash
docker run --rm \
  -v ai-chat_open-webui-data:/data \
  -v \$(pwd):/backup \
  alpine tar czf /backup/open-webui-backup-\$(date +%F).tar.gz -C /data .
```
*(Примечание: префикс `ai-chat_` зависит от имени папки проекта; проверить точное имя тома можно командой `docker volume ls`.)*
